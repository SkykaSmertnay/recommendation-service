# Recommendation Service

Spring Boot service for recommending banking products to users based on transaction history and rule-based logic.

## Project goal
The project implements an MVP of a recommendation service for a bank.  
The service analyzes user transactions and returns product recommendations through a REST API.

## Technologies
- Java 17
- Spring Boot
- Spring Web
- Spring Data JDBC / JdbcTemplate
- H2 Database
- Maven
